# Permission Protocol Receipt Format

This repository hosts the open specification for **`pp-receipt-v1`**, a portable, signed authority receipt format used by [Permission Protocol](https://permissionprotocol.com) and any system that wishes to interoperate.

- [📄 Read the spec](./RECEIPT-FORMAT-V1.md)
- [🧪 Reference fixtures](./fixtures/)
- [🔧 Reference verifier (TypeScript)](https://github.com/permission-protocol/pp-cli)
- [✅ Conformance suite](./conformance/)

The format is published under the **Apache 2.0** license. Independent implementations are welcomed.

## Status

- v1 is the current stable version.
- Maintained by [Permission Protocol](https://permissionprotocol.com).
- Issues and PRs welcome.
